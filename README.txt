# AnyKernel3 Tools

This directory should contain:
- busybox (for ARM64)
- magiskboot (for ARM64)

These binaries are required for the AnyKernel3 installation process.
You can obtain them from:
- busybox: https://github.com/osm0sis/Playground/tree/master/busybox
- magiskboot: Extract from Magisk APK

Place the ARM64 binaries in this directory before building the zip.
